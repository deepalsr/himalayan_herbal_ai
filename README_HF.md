# Himalayan Herbal AI

Antimicrobial bioactivity and toxicity prediction for compounds from
Himalayan medicinal plants. Trained on 309 compounds (curated + ChEMBL).

Random Forest (primary): F1=0.928, ROC-AUC=0.889
MLP (secondary): F1=0.889, ROC-AUC=0.900

Final-year BE Computer Engineering project, Pokhara University.
